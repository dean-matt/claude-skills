# Mode: spec

- **Source of items:** comments on the spec document or its issue, and the last
  `review-spec` findings.
- **Applying:** edit the document in place; keep a short changelog line only if the document
  already has one.
- **Replying:** answer each comment with `Applied` or `Declined — <reason>` and resolve the
  thread where the host allows.
- **Finish:** ask the user to approve the revised spec. Approval, not a label, ends this mode.
  Do not start `build` until the user says the spec is approved.
